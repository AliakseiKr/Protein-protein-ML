ProteinGraph — Machine Learning & Computational Biology Project
Designed and developed a Python-based machine learning system for predicting protein–protein interactions and discovering hidden relationships in complex biological datasets.

The project focuses on building an end-to-end data processing and ML pipeline, including data collection, preprocessing, feature engineering, integration of multiple data sources, and preparation of training datasets.

Key responsibilities and technologies:

Designed a modular and scalable Python architecture.

Developed data preprocessing, cleaning, validation, and feature extraction pipelines.

Engineered numerical features from protein sequences and biological properties.

Integrated and processed data from external scientific databases, including UniProt and BioGRID.

Implemented automated unit tests using pytest to ensure code reliability.

Used Git for version control and Linux for development.

Explored machine learning approaches for identifying previously unknown protein interactions.

Tech Stack: Python, pandas, NumPy, scikit-learn, PyTorch, pytest, Git, Linux.

The project combines software engineering, data science, and applied machine learning, with a strong emphasis on reproducibility, modular design, and processing complex, high-dimensional data.
